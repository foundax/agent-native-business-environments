# Contributing

We welcome concrete business scenarios, clearer contracts, design-feedback methods, and reproducible
experiments. Explain the task, the relationship or decision that was difficult, the change you propose, and
how you assessed its effect.

For code changes, run `npm test` and the relevant demo path. For page changes, record the viewport and
interactions inspected. Keep the reference runnable with Node.js built-ins. Use synthetic data and assets that
you are authorized to contribute. Distinguish implemented behavior, illustrative pseudocode, and production
experience in both language versions.

Useful questions include how domain projections affect agent work, how template briefs transfer design intent,
and how feedback changes the balance between quality and execution cost. Include the agent/model and tool
environment when discussing an agent experiment; scripted runs are a separate category.

For broader engineering discussions, contact contact@novariseintl.com.

`npm test`
和相关演示；页面修改记录实际检查过的尺寸与交互。使用合成数据和有权贡献的素材，保持中英文文档的实现范围一致。讨论 Agent 实验时注明模型与工具环境，并区分预设脚本演示和实际模型执行。
